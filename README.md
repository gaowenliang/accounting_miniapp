# 💰 记账助手 — 微信小程序

简洁高效的个人/家庭记账工具，支持多账本和共享记账。

## 项目信息

- **框架:** 微信小程序原生 + 微信云开发
- **本地路径:** `/home/gao/.openclaw/workspace/accounting_miniapp/`

## 设计理念

**首页即记账**：打开小程序直接就是记账页，3秒完成一笔。

**多账本体系**：
- 个人账本 — 本地存储，即开即用
- 共享账本 — 云端数据，多人协作（家庭/情侣/团队）
- 6位邀请码加入，参考养花小程序的家庭系统

## TabBar 结构

| Tab | 页面 | 说明 |
|-----|------|------|
| 📝 记账 | record | **首页**，直接记账，快捷分类 |
| 📋 明细 | bills | 按月查看，日期分组，筛选搜索 |
| 📊 统计 | stats | 月度/年度，分类占比，趋势图 |
| ⚙️ 管理 | manage | 账本管理、账户、预算、导出 |

## 核心设计决策

1. **金额用整数（分）** — 避免 0.1+0.2≠0.3
2. **首页即记账** — 最常用功能一步到位
3. **账本系统** — 个人/共享分离，共享走乐观写
4. **邀请码6位** — 简单可靠，参考养花家庭系统
