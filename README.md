# 💰 记账助手 — 微信小程序

简洁高效的个人记账工具，收支一目了然。

## 项目信息

- **AppID:** 待申请
- **框架:** 微信小程序原生 + 微信云开发
- **GitHub:** 待创建

## 设计理念

**轻量快速记账**：3秒完成一笔记录。首页即记账，分类清晰，统计直观。

**本地优先，云端备份**：本地 storage 即时响应，云函数后台同步，断网也不丢数据。

## 功能（V1 MVP）

| 功能 | 状态 | 说明 |
|------|------|------|
| 快速记账 | 🔨 | 金额、分类、备注、日期、账户 |

| 预算管理 | 🔨 | 月度预算、超支提醒 |
| 账户管理 | 🔨 | 微信/支付宝/现金/银行卡 |
| 数据导出 | 🔨 | CSV 导出 |

## 设计规范

- 主色：`#1A73E8`（蓝色 — 专业、信任）
- 收入色：`#4CAF50`（绿色）
- 支出色：`#FF5252`（红色）
- 背景：`#F5F6FA`
- 卡片圆角：24rpx，按钮圆角：44rpx

## 核心设计决策

1. **金额用整数（分）存储** — 避免 0.1+0.2≠0.3 浮点陷阱，显示时 /100
2. **本地存储即时响应** — 操作不卡顿
3. **分类数据本地缓存** — 减少云函数调用
4. **防刷限频** — 同用户每分钟不超过 30 条记录

## 部署步骤

1. 微信开发者工具打开项目
2. 上传所有云函数（`cloud/functions/` 下的 4 个）
3. 运行 `initCollections` 云函数创建集合
4. 集合权限设为 `{ "read": "creator", "write": "creator" }`

## 开发说明

- 小程序不支持 `div`，只能用 `view`
- 图片使用 `image` 组件
- 金额存储单位为分，显示时转换
