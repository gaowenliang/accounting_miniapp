# 💰 记账助手 — UI 设计规范

## 一、设计风格

### 设计关键词
**简洁、专业、高效、清晰**

### 色彩体系
```
主色     #1A73E8  蓝色 — 专业、信任、理性
辅色     #4285F4  亮蓝 — 按钮、高亮
收入色   #4CAF50  绿色 — 收入、正数
支出色   #FF5252  红色 — 支出、负数
背景     #F5F6FA  浅灰 — 柔和不刺眼
卡片     #FFFFFF  白色 — 纯净
文字主色  #2D3436  深灰 — 主要文字
文字次色  #90A4AE  灰色 — 辅助文字
预算警告  #FF9800  橙色 — 超支预警
```

### 字体规范
```
页面标题    34rpx  bold   #2D3436
卡片标题    30rpx  600    #2D3436
正文        28rpx  normal #2D3436
辅助文字    24rpx  normal #90A4AE
标签        22rpx  normal
金额强调    48rpx  bold   收入绿/支出红
数字统计    36rpx  bold   #2D3436
```

### 圆角规范
```
卡片圆角    24rpx
按钮圆角    44rpx（全圆角）
标签圆角    20rpx
弹窗圆角    28rpx
输入框圆角  16rpx
```

## 四、动画规范

| 动画 | 时长 | 缓动 | 使用场景 |
|------|------|------|----------|
| 淡入 | 200ms | ease | 页面切换 |
| 上滑 | 300ms | ease-out | 弹窗出现 |
| Toast | 300ms | ease | 操作反馈 |
| 数字滚动 | 500ms | ease-out | 金额变化 |

## 五、空状态设计

| 场景 | 显示 |
|------|------|
| 无账单 | 💰 + "还没有记账，记一笔吧" + 按钮 |
| 搜索无结果 | 🔍 + "没有找到相关账单" |
| 无预算 | "设置月度预算，控制支出" |
