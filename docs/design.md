# 设计规范 — 靛蓝（Indigo）主题

> 基于用户参考 UI 稿的风格制定

## 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#4F46E5` | 靛蓝，用于选中态、按钮、高亮 |
| 主色浅 | `#6366F1` | 渐变辅助色 |
| 主色极浅 | `#EEF2FF` | 选中背景、标签底色 |
| 主色深 | `#3730A3` | 深色文字 |
| 支出 | `#EF4444` → `#F87171` | 渐变红 |
| 收入 | `#10B981` → `#34D399` | 渐变绿 |
| AA/橙 | `#F59E0B` → `#D97706` | AA结算专用 |
| 页面背景 | `#F7F7FA` | 浅灰白 |
| 卡片 | `#FFFFFF` | 白底 |
| 标题 | `#1F2937` | 深灰 |
| 正文 | `#374151` | 中灰 |
| 次要 | `#6B7280` | 浅灰 |
| 提示 | `#9CA3AF` | 更浅灰 |
| 分割线 | `#F3F4F6` | 极浅灰 |

## 圆角

| 元素 | 圆角 |
|------|------|
| 卡片 | 24rpx |
| 按钮/输入框 | 16rpx |
| 胶囊按钮 | 44rpx（全圆角） |
| 人员头像标签 | 20rpx |
| 弹窗 | 28rpx |

## 阴影

```css
/* 卡片 */
box-shadow: 0 2rpx 16rpx rgba(79,70,229,0.05);
/* 渐变头部 */
box-shadow: 0 8rpx 32rpx rgba(79,70,229,0.25);
/* 提交按钮 */
box-shadow: 0 8rpx 24rpx rgba(239,68,68,0.2);
```

## 渐变

- 头部卡片：`linear-gradient(135deg, #4F46E5, #7C3AED)` 靛蓝→紫
- 支出按钮：`linear-gradient(135deg, #EF4444, #F87171)` 红
- 收入按钮：`linear-gradient(135deg, #10B981, #34D399)` 绿
- 趋势条：`linear-gradient(180deg, #4F46E5, #6366F1)` 靛蓝竖向

## 字体

| 层级 | 大小 | 字重 |
|------|------|------|
| 大标题 | 34rpx | 700 |
| 页面标题 | 30rpx | 700 |
| 正文 | 28rpx | 400/500 |
| 小字 | 24rpx | 400 |
| 提示 | 22rpx | 400 |
| 极小 | 20rpx | 400 |

## 间距

- 页面边距：28rpx
- 卡片内边距：24rpx
- 卡片间距：20rpx
- 列表项间距：14rpx（padding）
- 行内元素间距：8-12rpx

## 交互

- 按压反馈：`transform: scale(0.95)`
- 选中态：背景 `#EEF2FF` + 边框 `#4F46E5`
- 过渡：`transition: all 0.15s`
