# 📋 Release Notes

> 每次发版的变更记录

## v0.9.0 — 2026-06-14（首次发版）

### 🎉 核心功能

- **记账** — 首页即记账，3秒完成一笔
  - 收入/支出切换，自定义数字键盘支持加减运算
  - 13 支出分类 + 6 收入分类，单行 6 个 + 更多展开
  - 多币种支持（22 种货币），胶囊选择器，自动换算人民币
  - 拍照上传收据，永久保存，明细页可查看大图
  - 备注、日期、付款账户同一行
  - 预算超支提醒（80% 阈值）

- **明细** — 按月浏览，日期分组
  - 显示付款人、分摊方式（AA/独占/自定义）、分摊明细、备注
  - 金额按原始币种显示，外币附折合人民币
  - 编辑/删除账单，余额自动回滚
  - 搜索（关键词 + 金额）

- **统计** — 4 大分析维度
  - 月度：分类占比图、每日趋势、按币种/按账户子维度
  - 年度：月度收支趋势对比
  - 按人：每人收支明细、分类排名
  - AA结算：自动计算人均、已付/应收应付、贪心算法生成结算方案

- **管理** — 全量设置
  - 账本管理：个人账本 + 共享账本（邀请码加入）
  - 账户管理：微信/支付宝/现金/银行卡 + 自定义
  - 预算管理：月度预算 + 超支提醒
  - 成员管理：添加/删除/批量导入/历史恢复/分组
  - 币种排序、分类排序
  - 数据导出（CSV）、备份/恢复（JSON）
  - 错误日志查看

### 🔧 技术架构

- **框架**：微信小程序原生 + 微信云开发
- **存储**：本地优先（个人账本），云端同步（共享账本乐观写）
- **云函数**：billData（账单CRUD+账本）、accountData（账户）、exportData（导出）、initCollections（初始化）
- **防刷**：rateLimit 公共模块，每用户每分钟 30 次
- **性能**：按月索引（O(1) 查询）、统计签名缓存
